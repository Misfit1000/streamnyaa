# Desktop 0.1.8 — incremental candidate

Includes all changes in desktop-reliability-features-1 plus:
- Z/X subtitle timing adjustments use the per-release persisted offset, including immediate application and bounded values.
- Settings can save a shareable support report. Copy and export allow-list health scalars and exclude personal paths, raw error logs, credentials, stream URLs and session identifiers.
- A local episode-spoiler preference hides titles and episode stills in Watch's list/rail; episode numbers, selection and playback remain available. Series artwork remains visible. This is not comprehensive spoiler suppression throughout every screen or the player.
- Tauri and Cargo application versions updated to 0.1.8, same application identity.

Validation: TypeScript passed; 122 frontend tests in 33 files passed; 51 Rust tests passed; desktop contracts passed after their version expectations were updated; 466 Lua player-state assertions passed; 20-cycle control integration, 100-cycle control soak and deterministic stalled-stream integration passed.

Limitations: independent durable download queue/offline Library, shortcut-conflict editor, crash-session restoration, complete interactive diagnostics, full spoiler coverage and live acceptance remain unfinished. Existing downloads remain active-stream exports. The previously observed catalog HTTP 403 is unresolved; no access-control bypass attempted. Live playback, live account sync and isolated upgrade validation were not performed for this candidate. It is not a claim that every historical feature request is complete.

Cleanup policy: retain latest desktop-reliability-features-1 0.1.7 rollback and 0.1.8. Remove only explicitly identified superseded installer executables after successful packaging; retain their audit metadata. Do not delete source, account data or settings.
