## Batch-release follow-up

The downloader already supports selecting individual files from a pack. Automatic batch playback is not enabled by these changes: playlist fallback scoring alone is insufficient proof of the requested episode. A safe extension must inspect the release file manifest, verify installment and episode identity (including season/absolute numbering), exclude extras and samples, and select a unique matching file. Ambiguous packs require explicit file selection. Batch-derived availability should remain distinct from provider-confirmed airing metadata. Cache verified manifests by release hash, reuse the same pack for subsequent episodes, and keep whole-release downloads explicit. This is a follow-up design, not a completed acceptance claim for this installer.
